# polish-notation

Convert between Polish (Łukasiewicz) notation and conventional notation for logic, in the browser: [sean-reid.github.io/polish-notation](https://sean-reid.github.io/polish-notation/).

Type or paste a formula in either notation. The site detects which one it is, renders both forms, and gives you the LaTeX with one click, or an SVG or PNG download.

## Develop

```sh
npm install
npm run dev
```

## Test

```sh
npm test        # unit tests
npm run e2e     # Playwright end-to-end tests
```

## Build

```sh
npm run build
```
